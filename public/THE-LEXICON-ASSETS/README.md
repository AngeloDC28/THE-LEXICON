## File Naming Convention

Images in each folder follow the convention: `[slug]-NN.jpg`

For example, in `mcqueen-ss99`: `mcqueen-ss99-01.jpg`, `mcqueen-ss99-02.jpg`, etc.

Most folders contain 15 images. Numbers are zero-padded to two digits.

---

## Folder Structure

Each collection folder contains:
- `[slug]-NN.jpg` — sequential runway look images
- `NOTES.md` — curatorial notes, look sourcing guide, photo credits, and target look descriptions
