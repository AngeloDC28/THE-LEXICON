## Working method — this is the change

**Stop using pull requests. Commit and push directly to `main`.**

`CLAUDE.md` already specifies this: *"Commit at logical break points and push to main. Don't batch giant end-of-session megacommits."* The PR flow was introduced only to obtain a Vercel preview URL, and previews are behind Deployment Protection so they can't be checked by automation anyway. Pushing to `main` deploys straight to production, which has no protection wall and is therefore the only environment where you can actually verify your own work.

This is a solo repository with CI, a green `main`, and full git history. Every change here is reversible. Work accordingly: commit in logical chunks, push, verify against production, fix forward.

**Verification loop after every push:**

```
curl -s https://thelexicon.xyz/reviews/<slug>/ | grep -c "<a distinctive phrase from that review>"
```

Non-zero means the page is server-rendered and the rewrite exclusion works. If it returns 0, the `vercel.json` exclusion is wrong — fix it before continuing. Do this check yourself; don't ask.
